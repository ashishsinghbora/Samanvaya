# Security Policy

## Supported Versions

Currently, only the latest major release branch is supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 2.x.x   | :white_check_mark: |
| 1.x.x   | :x:                |

## Reporting a Vulnerability

Security is a core pillar of the Samanvaya architecture. We take all security vulnerabilities seriously. 

If you discover a security vulnerability within Samanvaya, please **DO NOT** create a public issue. Instead, please send an e-mail to the maintainers or use the private GitHub Security Advisories feature.

When reporting a vulnerability, please include:
* A detailed description of the vulnerability.
* A proof of concept (PoC) or instructions on how to reproduce the vulnerability.
* Any potential impact or risk assessment.

We will acknowledge your report within 48 hours and provide a timeline for a fix. All reporters will receive credit in the security advisory once the patch is released.
