Article 1 • Overview

What is Samanvaya (समान्वय)?

Samanvaya is a production-grade planetary image registration and tie-point correspondence engine. It resolves Smart India Hackathon (SIH) Problem Statement 26166 formulated by the Indian Space Research Organisation (ISRO):

"Multi-modal, Sun angle and scale invariant image correspondence using Chandrayaan-2 optical images (OHRC, TMC and IIRS)."

The Real-World Lunar Photogrammetry Problem

The Moon has no atmosphere, meaning sunlight creates intense contrasts: razor-sharp, pitch-black shadows with zero ambient diffusion. When Chandrayaan-2 flies over the same crater during different orbital passes, the solar elevation and azimuth change drastically:

  • Morning Sun (Azimuth 60°): Shadows fall West, illuminating Eastern rim walls.
  • Afternoon Sun (Azimuth 240°): Shadows fall East, illuminating Western rim walls.
  • Extreme Scale Gaps: OHRC has a Ground Sampling Distance of ~0.25 m/pixel, while TMC-2 is 5.0 m/pixel (a 20× difference), and IIRS is 80 m/pixel (a 320× difference).
What Samanvaya Delivers

Samanvaya achieves sub-pixel alignment error (RMSE < 0.40 px) across 180° shadow inversions by isolating illumination-invariant wave frequency step edges rather than raw intensities.

Article 2 • Physics & Failure Modes

Why Did We Build This? (Classical CV Failures)

Standard computer vision algorithms like SIFT, ORB, SURF, and Normalized Cross Correlation (NCC) fail catastrophically on lunar orbital imagery.

1. Gradient Inversion (∇I Anti-Correlation)

SIFT and ORB descriptors rely on local image intensity gradients. When solar shadows flip 180°, the gradient vectors point in exact opposite directions. Raw pixel intensity correlation is ρ = -0.9627, making descriptor matching statistically impossible.

2. Non-Lambertian Lunar Regolith

Terrestrial vision assumes Lambertian diffuse scattering. Lunar particulate regolith dust exhibits severe retro-reflective backscattering described by the Lommel-Seeliger law, introducing nonlinear non-uniform brightness across orbital swaths.

3. The 20× Scale Octave Breakdown

Classical Gaussian scale spaces can only bridge up to 1.5×–2.0× scale ratios before keypoint descriptors diverge. OHRC (0.25m) vs TMC-2 (5.0m) requires a robust decimation and deep transformer feature extractor.

Article 3 • Rigorous Theory

Mathematical Formulation & Core Algorithms

1. Lommel-Seeliger Scattering Model & 3D DEM Facet Normals

n = [-∂z/∂x, -∂z/∂y, 1]ᵀ / sqrt( 1 + (∂z/∂x)² + (∂z/∂y)² )
cos(i) = n · s,   cos(e) = n · v = n_z
R_LS(i, e) = cos(i) / ( cos(i) + cos(e) )

Calculates facet-level surface normals using Sobel elevation gradients from DEMs, removing illumination burnout along steep 20°–45° crater walls.

2. 2D Log-Gabor Zero-DC Phase Congruency

G(r, θ) = exp( -[ln(r/f₀)]² / 2[ln(σ_f)]² ) · exp( -[Δθ]² / 2σ_θ² )
M_max = 0.5 · [ (S_xx + S_yy) + sqrt( (S_xx - S_yy)² + 4·S_xy² ) ]

Because G(0, θ) = 0, the filter bank has strictly zero DC response. Kovesi moment analysis derives the illumination-invariant step edge map M_max (ρ = +0.9295).

3. 2D Parabolic Taylor Sub-Pixel Hessian Optimization & Covariance

f(x, y) = a·x² + b·y² + c·x·y + d·x + e·y + f
Continuous Peak: δ* = -H⁻¹·g = [ (-2bd + ce)/(4ab - c²), (-2ae + cd)/(4ab - c²) ]ᵀ
H_inv = [[2b, -c], [-c, 2a]] / (4ab - c²)
Uncertainty: σ_x² = |H_inv[0,0]|,  σ_y² = |H_inv[1,1]|,  Weight W = sqrt(4ab - c²)

Solves the continuous maximum point with sub-pixel precision (0.283 px < 0.40 px). Exports measurement covariance matrices directly for USGS ISIS3 Jigsaw bundle adjustment.

4. 8×8 Spatial Lattice Partitioning & Shannon Spatial Entropy

H_spatial = - Σ [ p_k · log₂(p_k) ] / log₂(K),   K = 64 cells,  p_k = n_k / N_total

Ensures tie-points achieve uniform dispersion across the entire lunar scene without clumping along high-relief crater rims (H = 0.986 / 1.0).

5. 320× Multi-Modal Hierarchical Scale Bridge & IIRS Continuum PCA

OHRC (0.25m) → TMC-2 (5.0m) → IIRS (80m)
H_OHRC→IIRS = H_TMC2→IIRS · H_OHRC→TMC2

Extracts 1.0–1.25 µm continuum reflectance and performs PCA dimensionality reduction on 256 hyperspectral channels for scale-invariant cross-attention.

Article 4 • Applications

Who Can Use Samanvaya?

🛰️ Planetary Scientists & Space Agencies

Automated co-registration of orbital swathes for global basemaps (Chandrayaan-2, Artemis, LRO, Chang'e).

🚀 Autonomous Lunar Landers (TRN)

Terrain Relative Navigation: real-time matching of descent camera frames against onboard DEMs in < 50ms.

🗺️ GIS Cartographers

Export verified Ground Control Points (GCPs) for USGS ISIS3 Jigsaw, QGIS, and ArcGIS Pro bundle adjustment.

🌍 Earth Remote Sensing & Defense

Cross-season satellite image alignment over mountainous terrain where low winter sun angles create severe shadows.

Article 5 • User Manual

Complete Step-by-Step User Manual

1. Launch the Interactive Web Portal
make run
# Or: samanvaya ui --port 8501

Open the live portal at https://ashishsinghbora.github.io/Samanvaya/ (or use http://localhost:8501 for local development). Use the demonstration pair or upload real GeoTIFFs, then run the alignment pipeline.

2. Run Headless CLI Alignment
samanvaya align -s source_ohrc.tif -r ref_lro.tif -o output/

Performs headless alignment and exports registered GeoTIFF, structured JSON evaluation report, and residual scatter plot.

3. Run Automated Tests
make test
# Or: samanvaya test

Executes all 38 unit and integration tests across the repository.

Article 7 • FAQ

Frequently Asked Questions

Q: How does Phase Congruency differ from edge detectors like Canny or Sobel?

Canny and Sobel detect gradient magnitude |∇I|, which relies on intensity contrast. When lighting reverses, gradients reverse. Phase Congruency detects points of order in the frequency domain, which peak at physical step edges independent of magnification or contrast polarity.

Q: What is the significance of the ISRO 0.40 px RMSE mandate?

In 3D planetary reconstruction, horizontal registration errors propagate into vertical elevation errors multiplied by the base-to-height ratio. Sub-pixel error (< 0.40 px) is essential to eliminate artificial cliff artifacts in lunar DEMs.
